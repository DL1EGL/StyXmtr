# StyXmtr

StyXmtr turns an ADALM-Pluto or Pluto Plus into a transceiver for the QO-100 geostationary satellite and for 2 m, 70 cm, 23 cm and 13 cm. It is written by Claude Code in co-operation with Robert Breuer, DL1EGL and runs on Windows, on the Mac (Apple silicon) and on the Raspberry Pi.

This repository holds the releases only. On the [Releases](https://github.com/DL1EGL/StyXmtr/releases) page you find the installer for Windows, the app for the Mac, the archive for the Raspberry Pi, the plugin for the Logitech MX Creative Console and the user manual in six languages.

## What it does

- Receives and transmits SSB, CW, AM, FM, data modes (USB-D, LSB-D) and RADE (FreeDV) through a Pluto, either on this computer or through a PlutoTRX service on a Raspberry Pi at the dish.
- Locks onto the QO-100 beacon and keeps your frequency steady, so the LNB drift disappears.
- Works in simplex on 2 m, 70 cm, 23 cm and 13 cm, and receives from 70 MHz to 6 GHz as far as the Pluto covers it.
- Shows a large waterfall, a detail view around the VFO and of the audio, an S-meter plot and the beacon itself.
- Reads the multimedia beacon of AMSAT-DL: DX spots, bulletins and the live page qo100info.html.
- Brings a voice keyer, VOX with anti-VOX, a microphone equalizer and a rigctld output for WSJT-X.
- Can be run from a MIDI controller (learn any control, LEDs, ready-made templates) or from the Logitech MX Creative Console with its own plugin.

The user interface and the manual are available in German, English, Spanish, French, Italian and Portuguese.
